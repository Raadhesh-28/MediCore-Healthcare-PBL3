# MediCore Healthcare Management System

A healthcare management dashboard built as part of
DevOps PBL3.

## Technologies

- HTML and CSS
- Docker
- Docker Hub
- Kubernetes
- Jenkins
- Git and GitHub

## Features

- Healthcare administration dashboard
- Patient overview
- Appointment management interface
- Docker containerization
- Kubernetes deployment with two replicas

## Docker Image

raadhesh/healthcare-app:v1

## Kubernetes Deployment

- Deployment: healthcare-deployment
- Replicas: 2
- Service: healthcare-service
- NodePort: 30082

## Project Objectives

1. CI/CD Pipeline using Jenkins
2. Blue-Green Deployment
3. Secure DevOps implementation
